# EMPEZAR AQUÍ · KONA OS 2030

**Esta es una nueva base de aplicación**, limpia y separada de la v8 anterior. No sobrescribas la antigua sin guardar copia.

## En 3 pasos

1. Descarga y descomprime el ZIP. Si tu repositorio actual de GitHub sigue conteniendo versiones antiguas, prueba primero subiendo todos los archivos a un **repositorio nuevo**, por ejemplo `Kona-OS-2030-Limpio`, y activa Pages en `Settings → Pages → main / (root)`. El contenido a subir es lo que está *dentro* de la carpeta, no la carpeta misma.
2. Abre la URL de GitHub Pages desde el móvil y pulsa **Añadir a pantalla de inicio** para usarlo como app.
3. En **Calendario**, el plan provisional de la primera semana del 2/11 aparecerá al cargar. Los domingos tendrás el botón **Importar** para cargar el JSON semanal que te entregue ChatGPT, o **Buscar plan publicado** si me has pedido que actualice el archivo `plan-semana.json` desde GitHub.

## Primera semana provisional

Semana del 2–8 noviembre 2026: **5 h 35 min**; 3 sesiones de running suaves y 3 de bici fácil; descanso jueves. Es una **propuesta inicial** sujeta a evolución de la recuperación y las indicaciones médicas, no una orden de realizarla sin revisión.

## Informe dominical

Abre **Domingo → Copiar informe** y pégalo en el chat con tus sensaciones. Analizaremos las cuatro disciplinas, la carga real y el sueño para construir el siguiente plan.

## Google Health y Strava

La web base es útil desde ya, pero las conexiones **no están activadas todavía**. Para leer Google Health se requiere un conector Android autorizado para Salud Conectada; la API de Strava para nuevas apps de desarrollador exige suscripción en 2026. Si mantenemos la condición de coste cero, tendremos que evaluar qué actividades puede compartir Strava con Salud Conectada sin pérdida de datos importantes.

## Datos en móvil y PC

Sin Supabase activado, cada navegador almacena sus datos por separado. Para disponer de tus registros en varios dispositivos sigue `README.md → Cuenta privada opcional en Supabase` y conserva copias de seguridad periódicas.

**Nunca subas los datos de sueño, HRV o el archivo de copia personal a un repositorio público de GitHub.**
